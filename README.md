Smart Attendance System
Overview

Smart Attendance System is a web-based attendance management platform that automates attendance tracking using face recognition technology. The system helps educational institutions reduce manual work, improve accuracy, and maintain attendance records efficiently.

Features
Face Recognition Attendance
Student Registration
Attendance Tracking
Secure Login System
Attendance Reports
Database Integration
Real-Time Attendance Recording
Admin Dashboard
Tech Stack
Technology	Purpose
Python	Backend Logic
Flask	Web Framework
OpenCV	Face Detection & Recognition
MySQL	Database Management
HTML	Frontend Structure
CSS	Styling
JavaScript	Interactivity
